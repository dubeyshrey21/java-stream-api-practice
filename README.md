# Java Stream API Practice

A collection of Java Stream API practice programs covering filtering, sorting, mathematical operations, duplicate removal, and common coding exercises.

## About

This repository contains my hands-on practice with the Java Stream API. It includes individual Java programs to improve my understanding of stream operations and strengthen my problem-solving skills.

## Topics Covered

* Stream API basics
* Filtering and searching elements
* Sorting in ascending and descending order
* Finding maximum and second-highest numbers
* Calculating sums and averages
* Working with even, odd, positive, and divisible numbers
* Removing duplicate elements
* String and nested data processing

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/java-stream-api-practice.git
   ```

2. Navigate to the project directory:

   ```bash
   cd java-stream-api-practice
   ```

3. Compile and run any individual Java program. For example:

   ```bash
   javac SecondHighest.java
   java SecondHighest
   ```

   If your files have package declarations, compile and run them from the appropriate source directory.
